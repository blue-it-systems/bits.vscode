# BITS VS Code Extensions

This repository contains VS Code extensions developed by Blue IT Systems GmbH.

## Extensions

### C# Test Filter Helper

Located in `csharp-test-filter/`

Automatically detect C# test scope (assembly/class/method) for TUnit debugging.

See the [extension README](./csharp-test-filter/README.md) for more details.

## Development

To work on an extension:

1. Navigate to the extension folder (e.g., `cd csharp-test-filter`)
2. Install dependencies: `npm install`
3. Open VS Code at the repository root
4. Press F5 to launch the Extension Development Host

The workspace is configured with debug tasks for each extension.
