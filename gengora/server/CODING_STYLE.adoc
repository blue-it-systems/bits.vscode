== Naming Conventions

=== Private Fields

*Use `_PascalCase` with underscore prefix* for private fields:

[source,csharp]
----
// ✅ Correct
private readonly int _Width;
private readonly int _Height;
private readonly byte[,] _Buffer;
private readonly IBackend _InnerBackend;

// ❌ Incorrect
private readonly int width;
private readonly int _width;
private readonly int m_Width;
----

*Rationale*: Clear distinction from local variables and parameters, consistent with .NET conventions.

=== Local Variables and Parameters

Use `camelCase` for local variables, parameters, and method arguments:

[source,csharp]
----
// ✅ Correct
public void ProcessImage(string filePath, int maxWidth)
{
    var imageData = File.ReadAllBytes(filePath);
    var scaleFactor = this.CalculateScale(maxWidth);
}

// ❌ Incorrect
public void ProcessImage(string FilePath, int MaxWidth)
{
    var ImageData = File.ReadAllBytes(FilePath);
}
----

=== Properties and Methods

Use `PascalCase` for public properties, methods, classes, and interfaces:

[source,csharp]
----
// ✅ Correct
public class OcrEngine
{
    public int Width { get; }
    public int Height { get; }
    
    public async Task<OcrResult> ProcessAsync(Image image)
    {
        // Implementation
    }
}

// ❌ Incorrect
public class ocrEngine
{
    public int width { get; }
    
    public async Task<OcrResult> processAsync(Image image)
    {
        // Implementation
    }
}
----

== Code Style

=== Razor Markup Conventions

*DO NOT use `this.` prefix in Razor markup* - it adds unnecessary noise to the view layer:

[source,razor]
----
<!-- ✅ Correct - Clean and readable -->
<SideNavigation ViewModel="@_viewModel" />
<MudText>@_userName</MudText>
<MudButton OnClick="HandleClickAsync">Click Me</MudButton>

@if (_isVisible)
{
    <div>Content: @_content</div>
}

<!-- ❌ Incorrect - Unnecessary clutter -->
<SideNavigation ViewModel="@this._viewModel" />
<MudText>@this._userName</MudText>
<MudButton OnClick="this.HandleClickAsync">Click Me</MudButton>

@if (this._isVisible)
{
    <div>Content: @this._content</div>
}
----

*Rationale*:

* Razor markup is part of the view layer where `this.` is implicit and redundant
* Improves readability by reducing visual clutter
* Follows Blazor community conventions and Microsoft's own Razor examples
* The C# code-behind still uses `this.` for clarity in imperative code

*Exception*: Use `this.` in C# code blocks within Razor (e.g., `@code { }`) - those follow C# rules

=== Always Use `this.` Prefix

*Always use `this.` prefix* when accessing instance members (fields, properties, methods):

[source,csharp]
----
// ✅ Correct
public class ImageProcessor
{
    private readonly int _Width;
    private readonly int _Height;
    
    public int CalculateArea()
    {
        return this._Width * this._Height;
    }
    
    public void Resize(int newWidth, int newHeight)
    {
        this._Width = newWidth;
        this._Height = newHeight;
        this.UpdateBuffer();
    }
    
    private void UpdateBuffer()
    {
        // Implementation
    }
}

// ❌ Incorrect
public int CalculateArea()
{
    return _Width * _Height; // Missing this.
}
----

*Rationale*: Explicit `this.` makes it immediately clear when accessing instance members vs. local variables, improving code readability.

=== Collection Initializers

*Use `[]` syntax* for collection Initializers (C# 12+):

[source,csharp]
----
// ✅ Correct
private readonly List<string> _Operations = [];
private readonly Dictionary<string, int> _Cache = [];
private readonly HashSet<string> _ProcessedItems = [];

// ❌ Incorrect
private readonly List<string> _Operations = new List<string>();
private readonly Dictionary<string, int> _Cache = new Dictionary<string, int>();
private readonly HashSet<string> _ProcessedItems = new();
----

*Rationale*: Cleaner syntax, less verbose, follows modern C# conventions.

=== Expression-Bodied Members

Use expression-bodied members for simple properties and methods:

[source,csharp]
----
// ✅ Correct
public int Width => this._InnerBackend.Width;
public int Height => this._InnerBackend.Height;
public bool IsValid => this._Width > 0 && this._Height > 0;

public int GetArea() => this._Width * this._Height;

// ❌ Incorrect (for simple cases)
public int Width
{
    get
    {
        return this._InnerBackend.Width;
    }
}
----

For complex logic, use full method bodies:

[source,csharp]
----
// ✅ Correct (complex logic)
public async Task<OcrResult> ProcessAsync(Image image)
{
    var preprocessed = await this.PreprocessAsync(image);
    var detected = await this.DetectTextAsync(preprocessed);
    var recognized = await this.RecognizeTextAsync(detected);
    return this.BuildResult(recognized);
}
----

=== Inline Comments

*Use Title Case for ALL words* in inline comments:

[source,csharp]
----
// ✅ Correct
// Position Cursor (Convert 0-Based To 1-Based)
Console.SetCursorPosition(col + 1, row + 1);

// Initialize Buffer With Default Values
this._Buffer = new byte[this._Height, this._Width];

// Calculate Scale Factor Based On Target Dimensions
var scale = Math.Min(maxWidth / (float)width, maxHeight / (float)height);

// ❌ Incorrect
// position cursor (convert 0-based to 1-based)
Console.SetCursorPosition(col + 1, row + 1);

// Initialize buffer with default values
this._Buffer = new byte[this._Height, this._Width];
----

*Rationale*: Consistent capitalization improves readability and maintains professional documentation standards.

=== Code Formatting

==== Block Statements

*Always add blank lines before and after block statements* (including `if`, `for`, `while`, `foreach`, `switch`, etc.) when preceded or followed by other statements:

[source,csharp]
----
// ✅ Correct
var data = await this.LoadDataAsync();

if (data.IsValid)
{
    await this.ProcessDataAsync(data);
}

var result = this.BuildResult(data);

// ❌ Incorrect
var data = await this.LoadDataAsync();
if (data.IsValid)
{
    await this.ProcessDataAsync(data);
}
var result = this.BuildResult(data);
----

*Loops with preceding variable declarations* should have a blank line between the declaration and the loop:

[source,csharp]
----
// ✅ Correct
for (int row = 0; row < 24; row++)
{
    var rowSpan = buffer.GetBackRow(row);
    
    for (int col = 0; col < 80; col++)
    {
        rowSpan[col] = new Cell('X', Color.Red, Color.Black, Style.None);
    }
}

// ❌ Incorrect
for (int row = 0; row < 24; row++)
{
    var rowSpan = buffer.GetBackRow(row);
    for (int col = 0; col < 80; col++)
    {
        rowSpan[col] = new Cell('X', Color.Red, Color.Black, Style.None);
    }
}
----

*Multiple consecutive block statements* should also be separated:

[source,csharp]
----
// ✅ Correct
if (condition1)
{
    this.HandleCondition1();
}

if (condition2)
{
    this.HandleCondition2();
}

for (int i = 0; i < count; i++)
{
    this.ProcessItem(i);
}

// ❌ Incorrect
if (condition1)
{
    this.HandleCondition1();
}
if (condition2)
{
    this.HandleCondition2();
}
for (int i = 0; i < count; i++)
{
    this.ProcessItem(i);
}
----

==== Braces For Conditional Statements

*Use curly braces for complex conditional statements* that span multiple lines or contain complex expressions (3+ logical operators, method calls, or long expressions):

[source,csharp]
----
// ✅ Correct - Complex condition requires braces
if (row < 0 || row >= this._Height)
{
    throw new ArgumentOutOfRangeException(nameof(row), $"Row must be between 0 and {this._Height - 1}.");
}

// ✅ Correct - Method call in condition requires braces
if (this.IsValidPosition(x, y))
{
    this.ProcessCell(x, y);
}

// ❌ Incorrect - Complex condition without braces
if (row < 0 || row >= this._Height)
    throw new ArgumentOutOfRangeException(nameof(row), $"Row must be between 0 and {this._Height - 1}.");
----

*Simple single-statement conditionals without braces are acceptable* when both the condition and statement fit on two lines and are easy to read:

[source,csharp]
----
// ✅ Correct - Simple condition with simple statement
if (value == null)
    return;

// ✅ Correct - Simple boolean check with simple return
if (this.IsEmpty)
    return defaultValue;

// ✅ Correct - Single parameter check
if (index < 0)
    throw new ArgumentOutOfRangeException(nameof(index));

// ❌ Incorrect - Long statement should use braces
if (condition)
    this.CallMethodWithMultipleParameters(param1, param2, param3, param4);
----

*Always use braces for multi-line statements* or when the body contains block constructs:

[source,csharp]
----
// ✅ Correct - Multi-line body requires braces
if (this.IsEnabled)
{
    this.LogDebug("Processing started");
    this.ProcessData();
}

// ❌ Incorrect - Multi-line body without braces
if (this.IsEnabled)
    this.LogDebug("Processing started");
    this.ProcessData();  // This always executes!
----

*Guideline*: When in doubt, use braces. They prevent bugs and improve code clarity.

==== Return Statements

*Always add blank line before return statement* when preceded by other statements:

[source,csharp]
----
// ✅ Correct
public int CalculateTotal()
{
    var sum = 0;
    
    foreach (var item in this._Items)
    {
        sum += item.Value;
    }
    
    return sum;
}

// ❌ Incorrect
public int CalculateTotal()
{
    var sum = 0;
    foreach (var item in this._Items)
    {
        sum += item.Value;
    }
    return sum;
}
----

*Exception*: No blank line needed for single-statement methods:

[source,csharp]
----
// ✅ Correct (single statement)
public int GetCount()
{
    return this._Items.Count;
}

// ✅ Correct (expression-bodied)
public int GetCount() => this._Items.Count;
----

==== Throw Statements

*Always add blank lines before and after throw statements* when preceded or followed by other statements:

[source,csharp]
----
// ✅ Correct
public void ProcessImage(Image image)
{
    if (image == null)
        throw new ArgumentNullException(nameof(image));
    
    if (image.Width == 0 || image.Height == 0)
    {
        throw new ArgumentException("Image dimensions must be greater than zero.", nameof(image));
    }
    
    this.ValidateImageFormat(image);
    
    var processed = this.ApplyFilters(image);
}

// ❌ Incorrect
public void ProcessImage(Image image)
{
    if (image == null)
        throw new ArgumentNullException(nameof(image));
    if (image.Width == 0 || image.Height == 0)
    {
        throw new ArgumentException("Image dimensions must be greater than zero.", nameof(image));
    }
    this.ValidateImageFormat(image);
    var processed = this.ApplyFilters(image);
}
----

==== Multi-Line Statements

*Add blank lines before and after multi-line statements* when mixing with single-line statements:

[source,csharp]
----
// ✅ Correct
var simpleValue = 42;

var complexValue = this.CalculateComplexValue
(
    parameter1: value1,
    parameter2: value2,
    parameter3: value3
);

var anotherValue = this.GetValue();

// ❌ Incorrect
var simpleValue = 42;
var complexValue = this.CalculateComplexValue(
    parameter1: value1,
    parameter2: value2,
    parameter3: value3);
var anotherValue = this.GetValue();
----

==== Vertical Alignment

*Vertically align multiple assignments* in constructors and initialization blocks:

[source,csharp]
----
// ✅ Correct
public DbTextDetector
(
    InferenceSession session,
    DbDetectorOptions options,
    ILogger<DbTextDetector> logger
)
{
    this._Session = session ?? throw new ArgumentNullException(nameof(session));
    this._Options = options ?? throw new ArgumentNullException(nameof(options));
    this._Logger  = logger  ?? throw new ArgumentNullException(nameof(logger));
}

// ✅ Correct (property initialization)
var options = new OcrOptions
{
    DetectorType    = DetectorType.DB,
    RecognizerType  = RecognizerType.SVTR,
    Threshold       = 0.3f,
    BoxThreshold    = 0.6f,
    UnclipRatio     = 1.5f
};

// ❌ Incorrect (not aligned)
public DbTextDetector(
    InferenceSession session,
    DbDetectorOptions options,
    ILogger<DbTextDetector> logger)
{
    this._Session = session ?? throw new ArgumentNullException(nameof(session));
    this._Options = options ?? throw new ArgumentNullException(nameof(options));
    this._Logger = logger ?? throw new ArgumentNullException(nameof(logger));
}
----

==== Long Method Calls (>80 Characters)

*Break long method calls into multiple lines* with vertically aligned opening and closing braces/brackets:

[source,csharp]
----
// ✅ Correct (method call with named parameters)
var result = await this.ProcessImageWithOptionsAsync
(
    image: inputImage,
    detectText: true,
    recognizeText: true,
    threshold: 0.7f,
    cancellationToken: cancellationToken
);

// ✅ Correct (method call with positional parameters)
var detector = new TextDetector
(
    this._Session,
    this._Options,
    this._Logger
);

// ✅ Correct (fluent API)
var processedImage = image
    .Clone()
    .Resize(640, 480)
    .Grayscale()
    .ApplyGaussianBlur(5);

// ❌ Incorrect (closing parenthesis not aligned)
var result = await this.ProcessImageWithOptionsAsync(
    image: inputImage,
    detectText: true,
    recognizeText: true,
    threshold: 0.7f,
    cancellationToken: cancellationToken);

// ❌ Incorrect (exceeds 80 chars, not broken)
var result = await this.ProcessImageWithOptionsAsync(inputImage, true, true, 0.7f, cancellationToken);
----

==== Long Array/Collection Initializers

*Break long array/collection initializers* with vertically aligned brackets:

[source,csharp]
----
// ✅ Correct (array)
var mean = new[]
{
    0.485f,
    0.456f,
    0.406f,
    0.229f
};

// ✅ Correct (list with inline initialization)
var operations = new List<string>
{
    "Preprocess",
    "Detect",
    "Recognize",
    "Postprocess"
};

// ✅ Correct (dictionary)
var modelPaths = new Dictionary<string, string>
{
    ["detector"]   = "models/ppocr_det_v4.onnx",
    ["recognizer"] = "models/svtr_en.onnx",
    ["classifier"] = "models/angle_cls.onnx"
};

// ❌ Incorrect (closing bracket not aligned)
var mean = new[]
{
    0.485f,
    0.456f,
    0.406f };

// ❌ Incorrect (too long, should be multi-line)
var mean = new[] { 0.485f, 0.456f, 0.406f, 0.229f, 0.224f, 0.225f, 0.500f, 0.229f };
----

*Exception*: Short initializers (≤5 items, ≤80 chars) can stay on one line:

[source,csharp]
----
// ✅ Correct (short initializer)
var rgb = new[] { 255, 128, 64 };
var point = new Point { X = 10, Y = 20 };
----

==== Long Lambda Expressions

*Break long lambda expressions into multiple lines* with proper indentation:

[source,csharp]
----
// ✅ Correct (single-line lambda for simple expressions)
var squares = numbers.Select(x => x * x);

// ✅ Correct (multi-line lambda with single statement)
var filtered = items.Where(item =>
    item.IsValid && item.Value > threshold);

// ✅ Correct (multi-line lambda with block body)
var processed = items.Select
(
    item =>
    {
        var normalized = this.Normalize(item);
        var validated = this.Validate(normalized);
        
        return this.Transform(validated);
    }
);

// ✅ Correct (async lambda with block body)
var results = await Task.WhenAll
(
    items.Select
    (
        async item =>
        {
            var data = await this.LoadDataAsync(item);
            var processed = await this.ProcessAsync(data);
            
            return processed;
        }
    )
);

// ✅ Correct (complex LINQ query)
var query = this._Database.Users
    .Where(user =>
        user.IsActive &&
        user.LastLoginDate > cutoffDate &&
        user.Roles.Any(role => role.Name == "Admin"))
    .OrderBy(user => user.Name)
    .Select(user => new UserDto
    {
        Id        = user.Id,
        Name      = user.Name,
        Email     = user.Email,
        RoleCount = user.Roles.Count
    });

// ❌ Incorrect (complex logic on single line)
var processed = items.Select(item => { var normalized = this.Normalize(item); var validated = this.Validate(normalized); return this.Transform(validated); });

// ❌ Incorrect (poor formatting)
var results = await Task.WhenAll(items.Select(async item => {
    var data = await this.LoadDataAsync(item);
    return await this.ProcessAsync(data);
}));
----

*Lambda Parameter Guidelines*:

[source,csharp]
----
// ✅ Correct (single parameter, no parentheses)
var doubled = numbers.Select(x => x * 2);

// ✅ Correct (multiple parameters, with parentheses)
var combined = pairs.Select((key, value) => $"{key}={value}");

// ✅ Correct (explicit type when needed)
var parsed = strings.Select((string s) => int.Parse(s));

// ✅ Correct (discard parameter)
var indices = items.Select((_, index) => index);
----

=== Test Methods

Use one of the following patterns:

*Pattern 1*: `MethodName_Scenario_ExpectedResult`

[source,csharp]
----
[Test]
public async Task ProcessAsync_WithValidImage_ReturnsOcrResult()
{
    // Arrange
    var engine = new OcrEngine();
    var image = TestHelper.LoadSampleImage("invoice.jpg");
    
    // Act
    var result = await engine.ProcessAsync(image);
    
    // Assert
    await Assert.That(result).IsNotNull();
    await Assert.That(result.Text).IsNotEmpty();
}

[Test]
public async Task ProcessAsync_WithNullImage_ThrowsArgumentNullException()
{
    // Arrange
    var engine = new OcrEngine();
    
    // Act & Assert
    await Assert.ThrowsAsync<ArgumentNullException>(
        async () => await engine.ProcessAsync(null!));
}
----

*Pattern 2*: `Should{Behavior}` (BDD style)

[source,csharp]
----
[Test]
public async Task ShouldExtractTextFromValidImage()
{
    // Arrange
    var engine = new OcrEngine();
    var image = TestHelper.LoadSampleImage("invoice.jpg");
    
    // Act
    var result = await engine.ProcessAsync(image);
    
    // Assert
    await Assert.That(result.Text).IsNotEmpty();
}

[Test]
public async Task ShouldThrowWhenImageIsNull()
{
    // Arrange
    var engine = new OcrEngine();
    
    // Act & Assert
    await Assert.ThrowsAsync<ArgumentNullException>(
        async () => await engine.ProcessAsync(null!));
}
----

=== Test Method Signature

*Always use `public async Task`* for test methods:

[source,csharp]
----
// ✅ Correct
[Test]
public async Task ProcessAsync_WithValidInput_ReturnsResult()
{
    // Implementation
}

// ❌ Incorrect
[Test]

    // Implementation
}
----

*Rationale*: Consistent async/await patterns, even for synchronous tests (allows future extension without breaking changes).

== Examples

=== Complete Class Example

[source,csharp]
----
using System;
using System.Threading;
using System.Threading.Tasks;
using Microsoft.ML.OnnxRuntime;
using Microsoft.ML.OnnxRuntime.Tensors;
using SixLabors.ImageSharp;
using SixLabors.ImageSharp.PixelFormats;

namespace BITS.AI.Ocr.Detection;

/// <summary>
/// Detects Text Regions In Images Using The DB (Differentiable Binarization) Model.
/// </summary>
public class DbTextDetector : ITextDetector
{
    // Private Fields
    private readonly InferenceSession _Session;
    private readonly DbDetectorOptions _Options;
    private readonly ILogger<DbTextDetector> _Logger;
    
    // Constructor
    /// <summary>
    /// Initializes A New Instance Of The <see cref="DbTextDetector"/> Class.
    /// </summary>
    /// <param name="session">The ONNX Runtime Inference Session.</param>
    /// <param name="options">Configuration Options For The Detector.</param>
    /// <param name="logger">Logger For Diagnostic Messages.</param>
    /// <exception cref="ArgumentNullException">
    /// Thrown When Any Required Parameter Is Null.
    /// </exception>
    public DbTextDetector(
        InferenceSession session,
        DbDetectorOptions options,
        ILogger<DbTextDetector> logger)
    {
        this._Session = session ?? throw new ArgumentNullException(nameof(session));
        this._Options = options ?? throw new ArgumentNullException(nameof(options));
        this._Logger  = logger  ?? throw new ArgumentNullException(nameof(logger));
    }
    
    // Public Properties
    /// <summary>
    /// Gets The Name Of The Detection Model.
    /// </summary>
    public string ModelName => "PP-OCRv4-DB";
    
    /// <summary>
    /// Gets A Value Indicating Whether The Detector Is Ready For Inference.
    /// </summary>
    public bool IsReady => this._Session != null;
    
    // Public Methods
    /// <summary>
    /// Detects Text Regions In The Provided Image.
    /// </summary>
    /// <param name="image">The Image To Analyze.</param>
    /// <param name="cancellationToken">Token To Cancel The Operation.</param>
    /// <returns>A List Of Detected Text Regions With Bounding Boxes And Confidence Scores.</returns>
    /// <exception cref="ArgumentNullException">Thrown When <paramref name="image"/> Is Null.</exception>
    public async Task<List<TextRegion>> DetectAsync(
        Image<Rgb24> image,
        CancellationToken cancellationToken = default)
    {
        if (image == null)
        {
            throw new ArgumentNullException(nameof(image));
        }
        
        this._Logger.LogDebug(
            "Starting Text Detection On Image ({Width}x{Height})", 
            image.Width,
            image.Height
        );
        
        // Preprocess Image
        var inputTensor = this.Preprocess(image);
        
        // Run Inference
        var outputs = await this.RunInferenceAsync(inputTensor, cancellationToken);
        
        // Postprocess Results
        var regions = this.Postprocess(outputs, image.Width, image.Height);
        
        this._Logger.LogDebug("Detected {Count} Text Regions", regions.Count);
        
        return regions;
    }
    
    // Private Methods
    /// <summary>
    /// Preprocesses The Image For Model Input.
    /// </summary>
    /// <param name="image">The Input Image.</param>
    /// <returns>A Tensor Ready For Model Inference.</returns>
    private Tensor<float> Preprocess(Image<Rgb24> image)
    {
        // Calculate Target Size (Divisible By 32)
        var targetSize = this._Options.InputSize;
        var (width, height) = this.CalculateTargetSize(
            image.Width,
            image.Height,
            targetSize
        );
        
        // Resize Image
        image.Mutate(x => x.Resize(width, height));
        
        // Convert To Normalized Tensor [1, 3, H, W]
        var tensor = new DenseTensor<float>([1, 3, height, width]);
        
        // ImageNet Normalization
        var mean = new[] { 0.485f, 0.456f, 0.406f };
        var std = new[] { 0.229f, 0.224f, 0.225f };
        
        for (int y = 0; y < height; y++)
        {
            for (int x = 0; x < width; x++)
            {
                var pixel = image[x, y];
                
                // Normalize Each Channel
                tensor[0, 0, y, x] = (pixel.R / 255.0f - mean[0]) / std[0];
                tensor[0, 1, y, x] = (pixel.G / 255.0f - mean[1]) / std[1];
                tensor[0, 2, y, x] = (pixel.B / 255.0f - mean[2]) / std[2];
            }
        }
        
        return tensor;
    }
    
    /// <summary>
    /// Calculates Target Size Maintaining Aspect Ratio And Divisibility By 32.
    /// </summary>
    /// <param name="width">Original Width.</param>
    /// <param name="height">Original Height.</param>
    /// <param name="maxSize">Maximum Size For Either Dimension.</param>
    /// <returns>Tuple Of (Width, Height) Divisible By 32.</returns>
    private (int Width, int Height) CalculateTargetSize(int width, int height, int maxSize)
    {
        var scale = Math.Min(maxSize / (float)width, maxSize / (float)height);
        var newWidth = (int)(width * scale);
        var newHeight = (int)(height * scale);
        
        // Round To Nearest Multiple Of 32
        newWidth = (newWidth / 32) * 32;
        newHeight = (newHeight / 32) * 32;
        
        return (newWidth, newHeight);
    }
    
    /// <summary>
    /// Runs Inference On The Preprocessed Tensor.
    /// </summary>
    private async Task<Tensor<float>> RunInferenceAsync(
        Tensor<float> input,
        CancellationToken cancellationToken)
    {
        // Create Input Dictionary
        var inputs = new Dictionary<string, Tensor<float>>
        {
            ["x"] = input
        };
        
        // Run Inference (Offload To Thread Pool)
        var results = await Task.Run(
            () => this._Session.Run(inputs),
            cancellationToken
        );
        
        // Extract Output Tensor
        var output = results.First().AsTensor<float>();
        
        return output;
    }
    
    /// <summary>
    /// Postprocesses The Model Output To Extract Text Regions.
    /// </summary>
    private List<TextRegion> Postprocess(
        Tensor<float> probabilityMap,
        int originalWidth,
        int originalHeight)
    {
        // Threshold Probability Map
        var binary = this.ThresholdMap(probabilityMap, this._Options.Threshold);
        
        // Find Contours
        var contours = this.FindContours(binary);
        
        // Extract Boxes With Confidence
        var regions = [];
        
        foreach (var contour in contours)
        {
            var box = this.GetMinAreaRect(contour);
            var confidence = this.CalculateConfidence(probabilityMap, contour);
            
            if (confidence >= this._Options.BoxThreshold)
            {
                // Unclip Box (Expand Slightly)
                var unclipped = this.UnclipBox(box, this._Options.UnclipRatio);
                
                // Scale Back To Original Image Size
                var scaled = this.ScaleBox(unclipped, originalWidth, originalHeight);
                
                regions.Add(new TextRegion
                {
                    BoundingBox = scaled,
                    Confidence = confidence
                });
            }
        }
        
        return regions;
    }
}

/// <exception cref="ArgumentNullException">

=== Async/Await

* Use `async`/`await` consistently
* Include `CancellationToken` parameter for long-running operations
* Use `ConfigureAwait(false)` in library code

[source,csharp]
----
public async Task<OcrResult> ProcessAsync(
    Image image,
    CancellationToken cancellationToken = default)
{
    var preprocessed = await this.PreprocessAsync(image, cancellationToken)
        .ConfigureAwait(false);
    
    var result = await this.RunInferenceAsync(preprocessed, cancellationToken)
        .ConfigureAwait(false);
    
    return result;
}
----

=== Dispose Pattern

Implement `IDisposable` or `IAsyncDisposable` for resource management:

[source,csharp]
----
public class OcrEngine : IAsyncDisposable
{
    private readonly InferenceSession _Session;
    private bool _Disposed;
    
    public async ValueTask DisposeAsync()
    {
        if (this._Disposed)
        {
            return;
        }
        
        this._Session?.Dispose();
        this._Disposed = true;
        
        await Task.CompletedTask;
    }
}
